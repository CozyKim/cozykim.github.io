# 문항 2. 과거에 진행했던 프로젝트를 통해 발견한 직무 역량 상의 강점과 본 업무를 수행한다면 기대하는 시너지에 대해 구체적으로 작성해 주세요.

---

두 프로젝트를 통해 발견한 강점 두 가지를 말씀드리겠습니다.

**첫 번째 강점은, 리서치에서 서빙·운영까지 직접 끝내는 E2E 실행력입니다.** 7천만 개 이상의 상품이 3,360여 개 카테고리에 매핑되는 이커머스에서, 판매자 등록 오류로 카테고리가 잘못 매핑된 상품을 자동 탐지·교정하는 시스템을 설계하고 운영에 반영했습니다.

리서치의 출발점은 '수백만 건을 전수 검토할 수 없는데, 무엇을 의심할 것인가'였습니다. 입력 조합을 5단계로 나누어 실험을 설계했고, 임베딩으로 후보를 10개로 좁힌 뒤 오픈 LLM이 판단하는 2-Step을 채택했습니다. 수천 개 카테고리를 한꺼번에 주면 혼동이 커지므로 후보를 먼저 좁혀 정확도와 비용을 동시에 확보한 것입니다.

자동화의 핵심은 분류 신뢰도를 수치로 정의하는 것이었습니다. 다회 추론 합의율·출력 불확실성·카테고리 계층 간 거리를 조합해 자동 보정과 수동 검수 구간을 분기했습니다. 불확실성이 낮아도 검색어 부재 시 모델이 확신하면서 틀리는 패턴을 관찰했고, 문헌 검토를 거쳐 단일 지표가 아닌 다중 신호 조합으로 신뢰 구간을 설계했습니다.

가장 의미 있었던 발견은 저성능 카테고리의 절반이 '기타~' 계열이라는 점이었습니다. 탐색적 검증으로 이 그룹의 불확실성이 유의하게 높음을 확인하고, 모델 튜닝이 아니라 카테고리 체계 자체의 구조적 결함으로 진단했습니다. 모델에 투자할 곳과 데이터 구조를 바꿔야 할 곳을 구분한 이 판단이 실제 임팩트 방향을 잡는 데 결정적이었습니다. 시스템은 vLLM 자체 서빙으로 운영에 올라갔고, 식품 상품군 약 5%의 오매핑을 자동 교정해 반영하고 있습니다.

이 강점의 시너지는 명확합니다. 최신 모델을 빠르게 흡수해 PoC에서 멈추지 않고 서빙까지 끝내는 사이클은, 모델 특성을 이해한 실험 설계와 리서치를 동작하는 시스템으로 옮기는 역량에 직결됩니다.

**두 번째 강점은, 비정형 콘텐츠에서 메타정보를 추출하고 모델로 품질까지 보장하는 능력입니다.** 상품 상세에 없는 실제 사용 경험은 리뷰에 담겨 있다는 점에 착안해, 리뷰 텍스트에서 상품 특성을 자동 추출하는 프로파일링 파이프라인을 설계·운영했습니다.

파이프라인은 키프레이즈 추출→유의미성 분류→클러스터링→LLM 키워드 생성→품질 검증을 거칩니다. 유의미성 분류기는 ELECTRA 기반으로 직접 파인튜닝했습니다. 직접 라벨링한 데이터에 클러스터링 샘플링과 pseudo labeling을 조합해 약 5천 건 학습셋을 구축하고, LLM 호출 전 선별과 생성 키워드 품질 재검증에 모두 활용했습니다. 비용은 retrieval 캐싱으로 해결해, 주 40만 건 증분 처리에서 LLM 호출량을 약 99.4% 줄였습니다. 이 프로파일 데이터는 장바구니 추천에 적용되어 구좌 CTR을 약 3.19배 끌어올렸습니다.

이 강점과 웹툰의 시너지는 직접적입니다. 리뷰에서 상품 특성을 뽑듯, 웹소설·웹툰에서 캐릭터 성격·말투, 세계관 규칙, 서사 흐름 같은 메타정보를 구조화할 수 있습니다. 추출된 메타정보는 캐릭터챗 페르소나 일관성의 기반이자 IP 영상화 파이프라인의 입력이 될 수 있고, 파인튜닝 모델로 품질을 걸러내며 비용을 통제한 경험은 대규모 IP 콘텐츠를 다루는 환경에서 그대로 통합니다.

돌아보면 두 프로젝트에서 모델을 직접 학습·파인튜닝하고, 출력을 정량적으로 평가하고, 그 결과를 운영 시스템으로 옮기는 과정을 반복해 온 셈입니다. 팀이 가진 비전·생성·서빙 자산 위에 이 경험이 얹어진다면, 멀티모달 IP 경험을 리서치 단계에서 사용자에게 닿는 서비스까지 연결하는 데 기여할 수 있으리라 생각합니다.
